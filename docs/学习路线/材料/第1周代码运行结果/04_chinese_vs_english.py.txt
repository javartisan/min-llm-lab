小结论：
  - 词表是预训练定好的通用碎片表，不是汉字字典，也不是 Java 字典。
  - BPE：高频相邻片合并。英文常见词常 1 片；中文常多片。
  - 单个 token 不像汉字没关系，decode 后仍是正确中文。
  - 子词还有 WordPiece / Unigram；更粗有整词，更细有单字/纯字节。
  - 模型看的是 id 序列；微调通常改权重，不改这张词表。
