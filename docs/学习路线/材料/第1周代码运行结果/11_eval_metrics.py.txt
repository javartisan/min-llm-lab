【0】是不是行业常用？一句话
============================================================
  Reference    : 不是分数，是标准答案（行业都用这个输入）
  Token F1     : F1 常用；本项目是「字符去重集合」简化版

【2】Token F1：手算示例（字符集合）
============================================================
  参考 ref  = '不能实例化'
  预测 pred = '不能直接实例化'
  ref 集合  = ['不', '例', '化', '实', '能']   大小 5
  pred 集合 = ['不', '例', '化', '实', '接', '直', '能']   大小 7
  交集      = ['不', '例', '化', '实', '能']   大小 5
  Precision = 5/7 = 0.714  （预测里有多少字来自参考）
  Recall    = 5/5 = 1.000  （参考里有多少字出现在预测）
  F1        = 2PR/(P+R) = 0.833

  用真实参考、完全相同的预测 F1 = 1.000   （应接近 1）
  用真实参考、完全跑题的预测 F1 = 0.154   （应接近 0）
  F1 高 ≠ 一定懂了，只说明用字和标准答案像。顺序被忽略。

【4】NLL：手算示例（先不加载模型）
============================================================
  假设参考答案 3 个 token 的概率 P = [0.5, 0.4, 0.2]
  每个 token 的 -ln(P) = [0.693, 0.916, 1.609]
  平均 NLL = 1.073   （Negative Log-Likelihood，负对数似然，越低越好）
  PPL = exp(NLL) = 2.92
  PPL 是 Perplexity（困惑度）的缩写。
  读法：NLL 是对数空间里的意外程度；PPL 还原成「平均要在几个候选里猜」。

小结论：
  - Reference 是标准答案，不是指标。
  - F1 / Keyword 看「像不像」；NLL 看「模型内部有多确信」。
  - PPL = Perplexity（困惑度）= exp(NLL)，和 NLL 说的是同一件事。
  - 只有 NLL 是正统 LM 指标；本仓库 F1/Keyword 是小数据短答案的简化尺。
