## 0. 学习原则（先读这 5 条）

1. **先概念，再代码，再改参**：每学一个词，都要能用自己的话讲一遍。  
2. **每天输出一个“小结论”**：写在笔记里，避免只看不做。  
3. **疑虑优先消掉**：Encoder/Decoder 混淆不解决，后面 LoRA/DPO 会更懵。  
4. **本仓库是实验室**：所有概念尽量在本项目文件里找到对应物。  
5. **完整知识链记住这句**：  
   `Pretraining → Base → SFT → LoRA → QLoRA → DPO → Reasoning`

## 最终要掌握的知识链（对照大纲）

```text
Pretraining（海量文本预训练）
    ↓
Base Model（会续写，不一定会答题）
    ↓
SFT（监督微调：学会按标准答案回答）
    ↓
LoRA（只训练少量适配器参数）
    ↓
QLoRA（量化底座 + LoRA，更省显存）
    ↓
DPO（偏好对齐：更好回答 vs 更差回答）
    ↓
Reasoning（更复杂推理能力，后期拓展）
```

## 第 4 周：QLoRA（量化 + LoRA）

大纲目标：理解如何降低大模型微调的显存/内存需求。

### 现实约束
- QLoRA 在 NVIDIA CUDA 生态最成熟；Mac 上工具链可能不完整。  
- 本周以**原理 + 条件允许时的小实验**为主，不硬通。

### 本周总目标
建立“先压缩底座，再挂 LoRA”的意识。

### 建议日程

#### Day 1～2：概念学习
- 学：
  - 量化是什么（如 4-bit：用更少比特存权重）  
  - QLoRA = 量化底座（通常冻结） + LoRA 训练  
- 笔记对比：

| 方法 | 底座怎么存 | 训练什么 | 省什么 |
|---|---|---|---|
| 全量微调 | 高精度全参数 | 全部参数 | 不省 |
| LoRA | 高精度底座 | 小适配器 | 省可训练参数/部分显存 |
| QLoRA | 低比特底座 | 小适配器 | 进一步省显存 |

#### Day 3～4：环境可行性排查
- 查本机能否安装/使用 bitsandbytes 等量化组件  
- 若不能：改做“阅读案例 + 伪代码理解流程”，仍算完成概念目标  

#### Day 5～6：流程默写
默写 QLoRA 步骤：

```text
加载量化底座 → 注入 LoRA → 只训练 LoRA → 保存 adapter →（可选）合并/部署
```

#### Day 7：周复盘
- 回答：什么时候必须上 QLoRA？  
  （答案方向：模型更大、显存不够、又还想微调时）

  - [第 2 节：SFT 是什么](./材料/微调学习笔记.md#note-2)

- 对比表自己抄一遍：

| | SFT | DPO |
|---|---|---|
| 数据 | 问题 + 标准答案 | 问题 + 好答案 + 差答案 |
| 学什么 | 怎么答 | 哪种答更好 |

#### Day 2：手写偏好数据（非常重要）
从 `train.jsonl`/`test.jsonl` 选 10 个问题，写成：

```json
{"prompt":"...","chosen":"更好的短答案","rejected":"明显更差的答案"}
```

差答案例子：胡编、跑题、太长、错误知识点。

#### Day 3～4：理解 DPO 在优化什么
- 目标直觉：提高 chosen 相对 rejected 的优势  
- 常见顺序：**先 SFT，再 DPO**  
- 数据很少时不要急着上 DPO  

#### Day 5～6：读 TRL DPO 文档/示例（可不先跑通）
- 看 `DPOTrainer` 需要的字段  
- 尝试把你的 10～50 条偏好数据整理成可用格式  

#### Day 7：总复盘（5 周汇合）
默写完整链：

```text
Pretraining → Base → SFT → LoRA → QLoRA → DPO → Reasoning
```

并回答：
1. 每一步解决什么问题？  
2. 你当前项目已经走到哪一步？（SFT + LoRA）  
3. 下一步最缺的是什么？（通常是更多高质量数据）

### 第 5 周验收标准
- [ ] 能解释为什么要偏好数据  
- [ ] 手写至少 10 条 chosen/rejected  
- [ ] 能说清 SFT 与 DPO 损失目标差异（直观版即可）

## 贯穿 5 周的“疑虑消解清单”

每周至少回顾一次，直到能脱口而出：

1. tokenizer encode 和 Transformer Encoder 不是一回事  
2. 问答 LLM 通常没有独立 Encoder  
3. 没有 Encoder 也会 Embedding 成向量  
4. Decoder 层间传向量，最后才变成文字  
5. BERT 偏理解；BART 理解+生成；SmolLM 直接 Decoder 生成  
6. `tokenizer.json` 不是 Java 领域字符表  
7. SFT 学标准答案；DPO 学更好/更差  
8. LoRA 训补丁；QLoRA 先量化再训补丁  
9. `model.train()` 只换挡；`backward` 阅卷、`step` 改作业  
10. 大厂与脚本同一套公式；评测是多层门禁，没有一张统考卷
