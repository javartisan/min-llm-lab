## 学习路线 
- 第 1 周
    - SmolLM2-135M: 理解 Transformer、Tokenizer、Dataset、Forward、Loss、Backward。

- 第 2 周
    - 切换 MPS + 360M: 对比 CPU 与 MPS 的训练速度、内存使用以及 batch size。

- 第 3 周
    - LoRA:使用 1.7B 模型进行参数高效微调，理解为什么不需要更新全部参数。

- 第 4 周
    - QLoRA:学习量化 + LoRA，理解如何降低大模型微调的显存 / 内存需求。

- 第 5 周
    - DPO: 理解 Preference Alignment，以及为什么需要偏好数据。
