# SmolLM 微调学习大纲

5 周把这条链跑通，并在本仓库里找到对应代码与阅读材料：

```text
Pretraining → Base → SFT → LoRA → QLoRA → DPO → Reasoning
```

详细每日任务见 [学习计划.md](./学习计划.md)。材料索引见 [材料/README.md](./材料/README.md)。

设备：Intel Mac + PyTorch 2.2.2 时，第 1 周用 CPU 即可；更大模型按计划降配。

---

## 每周目标

| 周 | 大纲目标 | 本仓库怎么落地 |
|---|---|---|
| 第 0 阶段 | 分清 Encoder / Decoder / tokenizer encode | 精读问答流程文档 + `scripts/print_tokens.py` |
| **第 1 周** | Transformer、Tokenizer、Dataset、Forward、Loss、Backward | **`learn/week01/` 12 个脚本** + `scripts/sft001.py` |
| 第 2 周 | CPU vs MPS、内存、batch size | **`learn/week02/` 01～07**（MPS 不可用则 CPU 不同 batch） |
| 第 3 周 | 为何不必更新全部参数（LoRA） | `scripts/sft001.py` 的 `LoraConfig` |
| 第 4 周 | 量化 + LoRA 如何省显存（QLoRA） | 原理为主，本机工具链可能不完整 |
| 第 5 周 | 偏好对齐与偏好数据（DPO） | 手写 chosen/rejected，对照 SFT |

## 第 2～5 周（大纲级）

- **第 2 周：** 测设备、对比 batch 与内存；弄清 `_BaseAutoModelClass` / `AutoModelFor*` 工厂。MPS 不可用就做 CPU 不同 batch。概念见 [第2周-BaseAutoModelClass与Auto家族.md](./材料/第2周-BaseAutoModelClass与Auto家族.md)。

| 日 | 学什么 | 必跑脚本 |
|---|---|---|
| Day 1 | torch 版本、MPS 是否可用 | `learn/week02/01_probe_device.py` |
| Day 2 | `model.to(device)` + Auto 工厂（读材料） | `02_move_to_device.py` |
| Day 2～3 | 135M、batch=1，CPU vs MPS | `03_cpu_vs_mps.py` |
| Day 4～5 | batch 1→2→4；梯度累积 | `04_batch_size.py`、`05_grad_accum.py` |
| Day 6 | 尝试 360M（可选）；核对 `type(model)` | `06_try_360m.py`（`--download` 可选） |
| Day 7 | 填速度/内存表 + Auto 三问 | `07_week2_report.py` → `reports/week02_device.md` |  
- **第 3 周：** 冻底座、只训 LoRA 补丁；对照 `sft001.py` 的 `r` / `target_modules`。  
- **第 4 周：** QLoRA = 量化底座 + LoRA；Mac 上以原理为主。  
- **第 5 周：** SFT 学怎么答，DPO 学哪种更好；先手写偏好数据。

每日命令与验收清单见 [学习计划.md](./学习计划.md)。

## 验收（对照大纲）

第 1 周结束应能：

- 讲清训练一步的 8 个框，并指出对应 `learn/week01` 脚本  
- 区分 tokenizer encode 与 Transformer Encoder  
- 说明 `model.train()` 不是开始训练，`backward` 写梯度、`step` 才改权重  
- 知道本项目 `prompt/completion` → messages → chat_template

5 周结束应能把完整知识链讲给另一个初学者，并在全量 / LoRA / QLoRA 之间按内存做选择。
