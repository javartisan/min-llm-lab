# 按周学习脚本

这里只放「这一周要动手跑」的小脚本，和 `scripts/` 里的正式训练入口分开。

| 目录 | 对应计划 | 主题 |
|---|---|---|
| [week01/](./week01/) | 第 1 周 | Tokenizer、Dataset、Forward、Loss、Backward、SFT 格式、评测直觉 |

以后新增：`week02/`（设备与 batch）、`week03/`（LoRA）……按学习计划往后续即可。

一律在**仓库根目录**运行，例如：

```bash
python learn/week01/01_load_tokenizer.py
```
